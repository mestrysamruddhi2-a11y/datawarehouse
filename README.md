# datawarehouse
### Sales Data Warehouse using MySQL

Designed and implemented a **Sales Data Warehouse** using MySQL based on a **Star Schema**. The project includes Product, Region, and Time dimension tables along with a Sales Fact table.

Data was extracted from an existing sales database and loaded into the warehouse using **SQL queries and JOINs**. Primary and foreign keys were used to establish relationships between fact and dimension tables.

**Key concepts used:** MySQL, Data Warehousing, Star Schema, Fact & Dimension Tables, ETL, JOINs, Primary Keys, Foreign Keys, Aggregate Data.
